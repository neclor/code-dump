# Claude играет в Factorio через FLE — инструкция для вас

Здесь Claude сам играет в Factorio: пишет код для FLE (Factorio Learning Environment) и отправляет его в живую игру.
Ваша роль — запустить всё и **наблюдать** в обычном клиенте Factorio. Управлять игрой вам не нужно.

## Что нужно заранее (разово)

| Что | Состояние |
|---|---|
| Docker Desktop | должен быть запущен |
| Python 3.13 + пакет `factorio-learning-environment` | уже установлен |
| Factorio (Steam) версии **2.0.77** | у вас стоит (проверка: `factorio.exe --version`) |
| Образ `factoriotools/factorio:2.0.77` | уже скачан |

Версии клиента и сервера **должны совпадать** (2.0.77), иначе зайти нельзя. FLE не работает на Factorio 2.1.

## Как запустить

Откройте PowerShell в папке проекта (`C:\Git\code-dumb\fle`) и выполните:

```powershell
.\up.ps1 -Fresh -Client    # новая партия: сервер, клиент заходит сам, затем запускается агент
```

Эта одна команда делает всё: поднимает сервер Factorio (Docker), запускает ваш клиент и ждёт, пока он зайдёт, и только потом стартует агента и автоисследования.

- `.\up.ps1 -Client` — то же без пересоздания сервера (мир всё равно сбросится, см. ниже).
- `.\down.ps1` — остановить всё.

> Важно: `up.ps1` **всегда перезапускает сессию агента, а это сбрасывает мир**. Не запускайте его посреди партии, если не хотите потерять прогресс.

> **Клиент должен зайти ДО запуска агента.** В реальных условиях агент регистрирует в игре обработчики событий; клиент, зашедший позже, получает ошибку `script-event-mismatch` и не может войти. Поэтому всегда запускайте через `-Client`. Уже подключённый клиент работает без проблем.

## Как наблюдать

1. `.\up.ps1 -Fresh -Client` сам запустит клиент и зайдёт на `localhost:34197`; больше ничего делать не нужно.
2. Вы войдёте как **наблюдатель в режиме «бог»**: свободная камера без персонажа. Камера автоматически переносится к агенту.
3. Управление камерой: **WASD** — двигаться, колесо мыши — масштаб, **M** — открыть карту.
4. Персонажа Claude вы видите в игре как обычного игрока; все его действия происходят на ваших глазах.

Если экран чёрный — прокрутите колесо мыши (отдалить/приблизить) или подождите несколько секунд: камера переносится к агенту.

### Чего делать нельзя
- **Не закрывайте клиент во время партии.** Заново зайти в уже идущую партию нельзя (ошибка `script-event-mismatch`). Если закрыли, чтобы снова наблюдать, нужно начать новую партию: `.\up.ps1 -Fresh -Client` (прогресс сбросится).
- Если клиент зависает на «Connecting» или в клиенте ошибка про моды/версию, смотрите таблицу ниже.
- Не играйте сами персонажем и не ломайте постройки агента: он этого не ожидает.

## Скорость и правила игры

- Скорость игры сейчас **2x**. Поменять на лету: `python fp.py --speed 1` (или любое число).
- Новые правила: **реальные условия**. Каждое действие агента (ходьба, добыча, крафт) занимает реальное игровое время; ручной труд «наказывается» временем. Оценка идёт по времени игры.
- Игровое время пишется в логи: `3600 тиков = 1 минута`.

## Где что лежит

| Файл | Зачем |
|---|---|
| `up.ps1` / `down.ps1` | запуск и остановка всего |
| `join_client.ps1` | запуск клиента Factorio (вызывается из `up.ps1 -Client`) |
| `agentd.py` | долгоживущая сессия FLE (держит игру, сторожит наблюдателя) |
| `fp.py` | отправка кода агента в игру (`python fp.py -c "print(...)"`) |
| `researchd.py` | сам выбирает следующее исследование |
| `scripts/` | скрипты, которые Claude запускал в игре |
| `logs/actions.log`, `logs/actions.jsonl` | **лог всех действий** (код, вывод, награда, тик игры) |
| `.claude/GAME_PROMPT.md` | промт Claude для игры |
| `.claude/CLAUDE.md` | подробные заметки об устройстве и прогрессе |
| `docs/api.md` | справка по инструментам FLE |

## Если что-то сломалось

| Симптом | Что делать |
|---|---|
| `.\up.ps1` ждёт и падает по таймауту | проверьте, что Docker Desktop запущен |
| В клиенте «версия не совпадает» | клиент должен быть 2.0.77: Steam → Factorio → Свойства → Беты |
| В клиенте «Mods mismatch» | заходите только через `join_client.ps1` (он отключает DLC) |
| «script-event-mismatch» при входе | клиент зашёл слишком поздно: только `.\up.ps1 -Fresh -Client` |
| Клиент не пускает / «not whitelisted» | белый список выставляется при запуске: используйте `-Client` |
| Агент не отвечает | `.\up.ps1 -Fresh` (новая партия) |
| Сервер перезапустился сам | прогресс потерян, запустите `.\up.ps1 -Fresh` |

Логи сервера: `docker logs fle-factorio_0-1`. Логи сессии агента: `agentd.log`, `agentd.err`.
