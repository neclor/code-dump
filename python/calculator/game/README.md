На fx-9860GIII стоковый Python клавиши не читает — то же ограничение, что и на fx-CG50. Неблокирующий ввод там появляется только с PythonExtra (порт MicroPython от Lephenixnoir, add-in .g1a; поддерживает как раз fx-9860GIII / Graph 35+E II).

С PythonExtra появляется модуль gint, и паттерн игрового цикла такой:


from gint import *

x = 60
while True:
    clearevents()                 # обновить состояние клавиатуры (обязательно каждый кадр)
    if keydown(KEY_LEFT):  x -= 2
    if keydown(KEY_RIGHT): x += 2
    if keydown(KEY_EXIT):  break   # выход из игры

    dclear(C_WHITE)               # очистить буфер
    drect(x, 28, x + 8, 36, C_BLACK)
    dupdate()                     # вывести кадр на экран
keydown(KEY_...) возвращает True/False мгновенно, ничего не блокирует. Ключевой момент — звать clearevents() в начале каждого кадра, иначе матрица клавиш не обновляется.

Если нужны события «нажал / отпустил» (а не «зажато сейчас»):


ev = pollevent()
while ev.type != KEYEV_NONE:
    if ev.type == KEYEV_DOWN and ev.key == KEY_SHIFT:
        jump()
    ev = pollevent()
gint заодно даёт всю графику (dpixel, drect, dtext, dimage…) — она быстрее, чем casioplot, и рассчитана на игры. casioplot в PythonExtra тоже есть для совместимости, но мешать их не стоит.

Без PythonExtra, на заводской прошивке: неблокирующего ввода нет вообще. Максимум — input() между ходами (блокирует) для пошаговых игр, либо меню выбора до старта. Реалтайм-управление на стоке невозможен.


Установка PythonExtra на fx-9860GIII
1. Скачать add-in
Репозиторий: git.planet-casio.com/Lephenixnoir/PythonExtra (раздел Releases / сборки в теме на Planète Casio). Для fx-9860GIII / fx-9750GIII / Graph 35+E II нужен файл .g1a (не .g3a — тот для цветных fx-CG). Обычно называется PythonExtra.g1a.

2. Подключить калькулятор к ПК
USB-кабелем. На калькуляторе появится меню выбора режима — нажми F1 (USB Flash / передача данных). Калькулятор смонтируется как USB-флешка.

3. Скопировать файл
Перетащи PythonExtra.g1a в корень этого диска (основная память калькулятора; SD у GIII нет). Туда же кидай свои .py-скрипты.

4. Отключить
Безопасно извлечь диск, отсоединить кабель, на калькуляторе нажать AC/EXIT. Add-in ставится сам.

5. Запуск
MENU → иконка PythonExtra → EXE. Внутри выбираешь свой .py из списка и жмёшь EXE, либо правишь во встроенном редакторе.

Замечания
fx-9860GIII (SH4) запускает add-in'ы без всякой разблокировки — просто скопировал и работает.
Размер PythonExtra ~1 МБ, память GIII ~1.5–3 МБ — влезает, но следи за свободным местом.
Переносить .py можно тем же режимом USB Flash, либо через Casio FA-124.
Стоковый Python-режим калькулятора остаётся на месте отдельно — PythonExtra его не трогает.
