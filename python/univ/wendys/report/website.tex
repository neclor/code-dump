\section{Architecture du site web}

Chaque page du site est composée d'un menu de navigation à gauche, qui permet de sélectionner une des 9 pages de notre site,
ansi que du contenu même de la page.
Ces pages sont:
\begin{itemize}
\item Tables:
    \begin{itemize}
    \item Clients : permet d'afficher et de sélectionner des clients.
    \item Locations : permet d'afficher et de sélectionner des lieux.
    \end{itemize}
\item Events:
    \begin{itemize}
    \item Event Dashboard : le tableau de bord des événements.
    \item Events : permet d'afficher et de sélectionner des événements.
    \item New Event : permet d'ajouter des événements dans la base de donnée.
    \end{itemize}
\item CD:
    \begin{itemize}
    \item Cd Dashboard : affiche la disponibilité des CDs.
    \item Cd Stats : le tableau de bord des CDs, permet aussi de modifier les CDs.
    \item Cd New : permet d'ajouter des CDs dans la base de donnée.
    \end{itemize}
\item Genres:
    \begin{itemize}
    \item Taxonomy : permet d'ajouter des informations sur la taxonomie des genres.
    \end{itemize}
\end{itemize}
